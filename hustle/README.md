# HUSTLE ✳ — Make the unnecessary irresistible

Interactive invention laboratory for little daily frustrations, launched November 2026.

## Product

- 24 speculative inventions in five categories (food/delivery, home, everyday carry, work, social).
- Each concept: problem, unexpected mechanism, wow moment, user segments, adjacent use cases, estimated DIY prototype cost, first experiment, feasibility and risk.
- Search, sorting, category filter, favorites, compare up to three ideas, random discovery, local-only problem notebook.
- No paid services, backend, API keys, analytics or JavaScript dependencies. Static site works on mobile and desktop.

## Run and test

Open the file: hustle/index.html

Run the zero-dependency smoke tests:

    node hustle/qa.mjs

The tests validate markup, JavaScript compilation, 24-card rendering, unique identifiers, cost/score limits, searching, saving, comparing and opening idea details.

## Prototype and safety disclaimer

Prototype prices are engineering *hypotheses* in INR for small-scale demonstrations, not verified supplier quotations or finished-product costs. Need, delight and feasibility scores are subjective hypotheses, not market validation. The opportunity index uses pain 35%, delight 25%, feasibility 25% and prototype affordability 15%.

The original SNAPLINE prompt was a non-marking dart that could attach to arbitrary surfaces, carry goods via zipline and return. There is **no basis for claiming universal, damage-free, load-bearing attachment**. The website instead describes a controlled, guided system using compatible pre-installed docks and captive tether, tested only in an enclosed ground-level rig initially. Do not fire darts/projectiles or suspend parcels from unapproved exterior structures. Real installations need engineered mounts, safety factors, redundant fall prevention, obstruction sensing, rated brakes and property approval.

## Proposed validation order

1. **CABLE GHOST / SOCK PORTAL**: quickest experiments, lowest price, test ease of use.
2. **MUTE MUSHROOM / TRAYWAY**: strong demo videos, easy indoor prototypes, test desire.
3. **SNAPLINE**: strongest emotional hook, but only an enclosed, ground-level demo until a professional safety review.

## Deliberately not implemented

Production hardware, a remotely fired attachment, payment, public voting, a real-time delivery service, backend collection, server submissions, IP clearance or validated purchase intent. The feedback notebook stores only in the visitor's own browser.
